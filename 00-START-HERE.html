1 Get set up (about 20 minutes, once)

Install one tool. That's it — it brings Python with it. Full details & troubleshooting are in samples/SETUP.md.

Don't want to install anything? You can run every sample in your browser with zero setup using Google Colab (colab.research.google.com) or GitHub Codespaces — upload the samples folder, prefix a cell with !pip install for the packages, and run. Handy for trying it on any machine.

2 Learn the 6 steps (in order)

Each step = open the map to learn it, then run the sample to prove it. Click a step name to open its visual map.

3 Finish: prove it, then show it

Two different things, and most people skip the first. Ticking a box is not the same as being able to do something.

★ A realistic rhythm

Not sure how to pace it? Follow this. 30–60 minutes a day, and the road doesn't stop at week four.

WEEKS 1–3

Setup + Step 1, then Step 2. Get comfortable running samples. Read 2.4 carefully — it's the one that saves you an afternoon.

WEEKS 4–7

Step 3. The important one. Don't rush it and don't measure yourself against the calendar here. Build the agent twice.

WEEKS 8–11

Step 4 (quick — pick one framework and move on) and Step 5, taking real time over evaluation.

MONTHS 3–5

Step 6, including governance. Then your first portfolio project — the document extractor is the fastest one to something genuinely useful.

If you only have a few weeks, don't follow this at all. Follow the 20% path on the Critical Path instead: 1.2+1.3 → 2.5+2.6 → 3.1+3.2 → 5.4 → 6.7. Half-finishing every step is worse than fully finishing the five that matter.

How the files are named, so the folder itself tells you what to open:

00-START-HERE  ←  you are here
01- … 06-  the six steps, in order
guide-  companions — read any time, in any order
samples/  the code, one capstone per step

Numbers are the path; guide- files are optional companions. So if you ever lose your place, sort the folder by name and the next thing to open is the lowest number you haven't finished. The three guides — Critical Path, Exit Checks, Plan Audit — sit outside the sequence on purpose, because you'll come back to them repeatedly rather than once.
