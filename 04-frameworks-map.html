4.1

Why Frameworks — and Why Build Raw First

Backbone
abstractionboilerplate removedmagic & leaksversion churnlock-in
Mental modelA framework is your Step 3 loop with the plumbing pre-built. It only helps if you understand the loop well enough to debug when the abstraction leaks.

Frameworks give you managed state, retries, tracing hooks, tool wiring, and memory out of the box. The cost is abstraction you can't see through, fast-moving APIs, and some lock-in. Because you built the raw loop in Step 3, you'll be able to reason about what the framework is doing — and drop down to raw calls when you need to.

Common mistakes
  • Adopting a framework before understanding the loop → undebuggable magic.
  • Collecting five frameworks instead of getting good at one.
  • Fighting the framework's opinions instead of picking one that fits.

4.2

LangChain / LangGraph

Backbone · largest ecosystem
LangGraph state machinenodes / edgesLangChain integrationsLangSmith tracing
Mental modelLangGraph models an agent as a graph of nodes over explicit shared state — reach for it when control flow gets genuinely complex.

The most popular ecosystem: a huge integration library (LangChain), durable inspectable state machines (LangGraph), and first-class tracing (LangSmith). Powerful, but a steep curve and a lot of surface area.

Common mistakes
  • Drowning in LangChain's abstraction sprawl for a simple task.
  • Not pinning versions in a fast-moving library — things break between releases.
  • Modeling a linear flow as an elaborate graph.

4.3

Claude Agent SDK

Backbone · Anthropic-native
built-in looptoolssubagentsMCP built-in
Mental modelIf you're all-in on Claude, the Agent SDK gives you the loop, tools, subagents, and MCP wiring with the least glue — it's the engine behind Claude Code.

Native tool use, streaming, subagents, and MCP support out of the box. Less vendor-neutral than LangGraph, but the fastest path to a solid Claude agent — and it maps cleanly onto everything you learned in Steps 2–3.

Common mistakes
  • Expecting it to be provider-agnostic — it's Anthropic-specific by design.
  • Assuming it ships your domain tools — you still write those (3.2).
  • Not tracking SDK changes (it evolves alongside the API).

4.4

Choosing One

Backbone
control-flow complexityecosystemobservabilityescape hatch
Mental modelPick the simplest thing that fits, and prefer frameworks you can drop out of when you need raw control.

Judge on real criteria, not hype: how complex is your control flow, what integrations do you need, how good is the tracing, how vendor-locked are you, and can you escape the abstraction? For most single agents, a thin framework or raw SDK beats a heavy graph.

Common mistakes
  • Résumé-driven framework selection.
  • Ignoring the exit cost when you outgrow it.
  • Reaching for a multi-agent framework for a single-agent job.

LlamaIndex

Applied · RAG-first
data connectorsindexingquery engines
Mental modelIf your app is mostly retrieval, LlamaIndex is RAG-shaped where LangChain is agent-shaped.

Specializes in ingestion, indexing, and query pipelines over your data (3.3). Often paired with an agent framework rather than used alone — it owns the "know your data" half.

CrewAI / AutoGen

Applied · multi-agent (preview of Step 5)
role-based crewsconversational agentshandoffs
Mental modelThese orchestrate multiple agents — reach for them only when one agent genuinely isn't enough (that's Step 5's whole question).

CrewAI models role-based "crews"; AutoGen models conversational multi-agent systems. Both are powerful but add coordination overhead — don't adopt multi-agent machinery until a single agent has actually failed you.

Rebuild your Step 3 agent in one framework

Take the working agent from Step 3 and rebuild it in
ONE framework (LangGraph or the Claude Agent SDK):
  • same tools, same RAG store, same task
  • measure: lines of code vs your raw version
  • note: what did the framework hide? what got easier?
    what got harder to debug?
  • keep BOTH versions side by side.

The goal isn't to love the framework — it's to see exactly what it abstracts, so you can choose it (or drop it) deliberately. Now you're ready to make agents cooperate.
