Becoming an AI Agent Engineer

A fast-track path from Python reflexes to shipping a production agent service. Each step is a visual mind map — backbone concepts in order, applied concepts alongside, and a capstone that proves you're ready for the next step. Every capstone has runnable sample code.

The whole track is one continuous build: Step 1's mock agent loop → Step 2 swaps in one real LLM call → Step 3 wraps that call in a loop with tools = an agent → Step 4 rebuilds it in a framework → Step 5 makes agents cooperate + speak MCP + get measured → Step 6 ships it. Finish with 3 portfolio projects.

Quick start: install uv, then from samples/ run uv init && uv add anthropic pydantic, set ANTHROPIC_API_KEY, and run Step 1 (needs no key) to confirm your setup. Model, provider, effort and pricing all live in one place — samples/config.py — and are overridable with $env:AI_MODEL / $env:AI_PROVIDER.

Also in samples/: evals.py (the 12-case suite with an LLM judge), mcp_dorm_server.py, and a Dockerfile — plus .github/workflows/eval.yml, the CI gate that fails the build when the pass rate drops.

📖 Read before you run. Every sample has a block-by-block walkthrough — what each part does, the concept it teaches, and why it was written that way rather than the obvious naive alternative. Each ends with a prediction to make before you press enter. They chain in order:
1 mock loop · 2 first call · 2b documents · 3 the agent · 3b retrieval · 4 framework · 5 orchestrator · 5b MCP · 6 the service · 6b governance
